# Winter '97 Rewind

Психоделическая 3D-сцена на Three.js: советская комната с видом на зимний ночной город 1997 года, которую перематывают VHS-лентой. Узоры изгибаются и переливаются, а 8-битная музыка искажается эффектами.

## Управление

- Кнопки деки: REW, FF, PAUSE, PLAY. Скорость ленты влияет и на картинку, и на тон музыки.
- REC: каждое нажатие включает следующий эффект, после последнего всё выключается.
- Клик по экрану: разрыв изображения.
- Пробел: пауза. ← и →: перемотка. R: REC.

Звук стартует после первого клика или нажатия клавиши: так требуют браузеры.

## Запуск

Откройте `index.html` в браузере с поддержкой WebGL 2. Three.js и Google Fonts подгружаются с CDN, так что нужен интернет.

Проект состоит из одного файла без сборки.
